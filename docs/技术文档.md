## 1. 项目技术规格

| 项目 | 规格 |
| --- | --- |
| 分辨率 | 1920 × 1080（Full HD，16:9） |
| 帧率 | 24 fps |
| 帧范围 | 250 帧（约 10.4 秒） |
| 渲染引擎 | EEVEE Next（`BLENDER_EEVEE_NEXT`） |
| 输出格式 | H.264 MP4（`avc1`）+ PNG 序列（RGBA） |
| 位深 | 8-bit / 通道 |
| 主文件 | `Fox-Animation.blend`（约 64 MB，未压缩保存） |

> 帧率 24 fps 由 MP4 的 `mdhd` 原子解析得出：timescale = 12288，duration = 128000，即 128000 / 12288 ≈ 10.42 秒 = 250 帧 / 24 fps。

## 3. 软件与版本

- **Blender 版本**：4.5（`.blend` 文件头 `BLENDER-v405`，即 `major * 100 + minor = 4 * 100 + 5`）；
- **架构**：64 位（文件头指针标识 `-`）、小端序（`v`）；
- **文件压缩**：未压缩（文件头直接为 `BLENDER`，非 gzip 魔数），便于直接读取内部数据块。

> 文件头解析：`BLENDER`（魔数，7 字节）+ `-`（64 位指针）+ `v`（小端序）+ `405`（版本号 4.5）。

## 4. 渲染引擎

- **当前引擎**：EEVEE Next（`BLENDER_EEVEE_NEXT`）；
- 场景中同时保留了 Cycles 相关设置（面板引用），但实际启用的渲染引擎为 **EEVEE Next**；
- EEVEE Next（Blender 4.2+ 的新版 EEVEE）提供实时全局光照、屏幕空间反射、阴影与体积光，适合本项目的快速渲染与毛发、次表面散射效果。

### 4.1 选择 EEVEE 的优势

- 毛发粒子（含子毛发插值）在 EEVEE 中渲染效率高；
- 次表面散射在 EEVEE Next 中有实时支持；
- 便于教程演示与快速迭代。

## 6. 角色绑定（Rigging）

### 6.1 骨架（Armature）

狐狸角色使用 **Armature（骨架）** 进行绑定，其中包含：

- **变形骨骼（`def_` 前缀）**：承担网格变形的骨骼，遵循角色绑定的标准命名约定；
- **身体/头部/耳朵/尾巴/腿部骨骼**：`body_`、`head_`、`ear_`、`tail_`、`arm_`、`leg`、`root_` 等骨骼；
- **尾巴拉伸骨骼（`boneStretcher`）**：用于实现尾巴的拉伸（Stretch）效果，常见于尾巴/脖子等需要弹性拉伸的绑定位。

### 6.2 骨骼集合

骨架使用了 **Bone Collections**（骨骼集合，Blender 4.x 特性）对骨骼进行分组管理。

## 8. 粒子与毛发系统

### 8.1 毛发系统

狐狸毛发使用 **Particle Hair（粒子毛发）** 系统：

- **基础毛发** + **插值子毛发（Interpolated Children）**；
- **Clump（成簇）**：控制毛发聚簇程度；
- **Kink（卷曲）**：控制毛发卷曲形态；
- **Roughness（粗糙度）**：控制毛发散射 / 柔顺程度。

这些参数共同塑造了狐狸蓬松、柔软的毛发质感。

### 8.2 粒子系统对象

- 场景存在多个 `ParticleSystem` / `ParticleSettings`，分别用于狐狸毛发及其它粒子效果（如落叶、火星等）；
- `GRparticles` 集合专门用于组织粒子相关对象。

## 9. 材质与着色器

### 9.1 着色器工作流

项目采用 **Principled BSDF（原理化 BSDF）** 作为核心着色器，配合多类节点构成完整的 PBR 材质。

### 9.2 关键着色器节点

| 节点类型 | 用途 |
| --- | --- |
| `ShaderNodeBsdfPrincipled` | 核心 PBR 着色器 |
| `ShaderNodeTexImage` | 图像纹理采样 |
| `ShaderNodeTexCoord` | 纹理坐标（UV） |
| `ShaderNodeMapping` | 纹理映射变换 |
| `ShaderNodeSeparateXYZ` | 分离 XYZ 通道 |
| `ShaderNodeValToRGB`（ColorRamp） | 颜色渐变 / 映射 |
| `ShaderNodeMix` | 颜色/数值混合 |
| `ShaderNodeTexGradient` | 渐变纹理 |
| `ShaderNodeEmission` | 自发光（火焰等） |
| `ShaderNodeNormalMap` | 法线贴图解析 |
| `ShaderNodeTexNoise`（噪声） | 随机细节（皮肤次表面变化） |

### 9.3 次表面散射（狐狸皮肤）

狐狸皮肤材质启用了完整的次表面散射参数组：

- **Subsurface Weight**（次表面权重）
- **Subsurface Scale**（次表面尺度）
- **Subsurface Radius**（次表面半径）
- **Subsurface IOR**（次表面折射率）
- **Subsurface Anisotropy**（次表面各向异性）

这些参数使狐狸皮肤在光照下呈现通透、柔软的质感。

### 9.4 纹理贴图资源

| 贴图 | 用途 |
| --- | --- |
| `head.png` / `body.png` / `tale.png` | 狐狸身体/头部/尾巴手绘贴图 |
| `texture-04.png` | 参考 / 教程纹理 |
| `Wood059_4K_Color / Roughness / NormalGL / NormalDX` | 木材 PBR（ambientCG） |
| `Bark001_4K_Color / Roughness / Normal / Displacement` | 树皮 PBR（ambientCG） |

## 10. 修改器

场景中使用的修改器（按出现频率）：

| 修改器 | 说明 |
| --- | --- |
| **Subdivision Surface（细分曲面）** | 使用最频繁，用于提升模型平滑度 |
| **Displacement（置换）** | 树皮等表面的立体细节（配合置换贴图） |
| **Solidify（实体化）** | 为薄壁模型（如树叶、蘑菇）增加厚度 |
| **Armature（骨架）** | 将网格绑定到狐狸骨架 |
| **Bevel（倒角）** | 边缘倒角 |
| **Shrinkwrap（收缩包裹）** | 表面贴合（如苔藓贴合树干） |
| **Mirror（镜像）** | 对称建模 |
| **MultiRes（多级精度）** | 多级精度雕刻 |

> **Subdivision Surface** 出现次数最高（427 次），说明高模细节主要依赖细分曲面实现，是本项目最重要的建模修改器。

## 13. 合成与后期处理

项目的 **合成器（Compositor）** 包含以下节点：

| 节点 | 说明 |
| --- | --- |
| `Blur`（模糊） | 柔化 / 景深模拟 |
| `Glare`（泛光） | 高光泛光（Bloom / 光晕） |
| `Color Balance`（色彩平衡） | 色调统一 |

## 16. 性能与优化

- **渲染引擎**：EEVEE Next 实时渲染，显著快于 Cycles，适合毛发与次表面散射的快速预览与最终输出；
- **毛发插值**：使用插值子毛发（Children + Interpolated）在低基础毛发数下获得高密度毛发，平衡性能与效果；
- **细分曲面**：高模细节依赖 Subdivision Surface，可在视口中降低细分级别以提升编辑流畅度，渲染时再提高；
- **实例化 / 关联副本**：场景中大量使用带 `.001` / `.002` 后缀的关联副本（如蘑菇、树木、龟背竹），通过实例化降低内存占用；
- **降噪**：后期 Denoise 节点减少噪点，允许使用较低采样数。

## 17. 技术要点总结

本项目的技术亮点：

1. **EEVEE Next 实时渲染**：在实时引擎中实现毛发、次表面散射与体积光效果；
2. **完整 PBR 材质管线**：Principled BSDF + 图像纹理 + 法线贴图 + 置换 + 渐变/混合节点；
3. **次表面散射皮肤**：完整的 Subsurface 参数组，塑造通透的狐狸皮肤；
4. **粒子毛发系统**：基础毛发 + 插值子毛发 + 成簇 + 卷曲 + 粗糙度；
5. **角色绑定**：Armature 骨架 + deform 变形骨骼 + 尾巴拉伸骨骼（`boneStretcher`）；
6. **动画驱动**：Action + FCurve + 关键帧 + Empty 空物体控制器；
7. **灯光链接（Light Linking）**：精细的逐对象布光控制；
8. **后期合成**：模糊 + 泛光 + 色彩平衡 + 降噪 + 镜头畸变；
9. **开源 PBR 素材**：ambientCG 4K 贴图 + HDRI 环境。
