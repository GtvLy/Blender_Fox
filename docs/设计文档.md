## 1. 项目概述

本项目是一个以**狐狸角色**为核心的 3D 动画短片，场景设定在充满生机的**森林环境**中。作品通过一只可爱的狐狸在自然环境中的动画表现，展示了角色建模、毛发、次表面散射皮肤、骨骼绑定、环境搭建、灯光与后期合成等一系列完整的 3D 制作流程。

### 基本规格

| 项目 | 规格 |
| --- | --- |
| 分辨率 | 1920 × 1080（Full HD，16:9） |
| 帧率 | 24 fps |
| 时长 | 250 帧（约 10.4 秒） |
| 渲染引擎 | EEVEE Next（实时渲染） |
| 输出格式 | H.264 MP4 + PNG 序列 |

### 项目定位

这是一个**学习型 / 作品集展示型**项目。它的价值在于：

- 完整覆盖了从角色到场景再到渲染的**全流程**制作；
- 综合运用了毛发、次表面散射、PBR 贴图、骨骼动画、粒子系统等**进阶技术**；
- 适合作为个人作品集（Portfolio）中的角色动画 / 场景演示案例。

## 2. 设计目标与创意方向

### 2.1 设计目标

1. **塑造一个有生命力的狐狸角色**——通过毛发、皮肤质感与骨骼动画，让角色"活起来"。
2. **营造一个可信且有氛围的森林场景**——通过丰富的植被、灯光与后期处理，营造自然、温暖的森林氛围。
3. **验证并展示完整的技术管线**——在单个项目中串起建模、材质、绑定、动画、粒子、渲染与合成。

### 2.2 创意方向

整体创意方向偏向**"写实与风格化的折中"**（semi-stylized / stylized realism）：

- **角色**采用偏向可爱、圆润的造型，皮肤带有次表面散射以呈现通透的质感；
- **毛发**使用粒子毛发系统，营造蓬松、柔软的狐狸毛发效果；
- **环境**采用 PBR 写实贴图（木纹、树皮、HDRI 环境），但整体色调经过后期统一，呈现出偏暖、柔和的画面氛围。

## 3. 视觉风格

### 3.1 风格基调

- **温暖**：暖色调的森林光线与后期色彩平衡，营造温馨氛围；
- **自然**：丰富的植被（树木、蘑菇、苔藓、草地、龟背竹、棕榈树）构成层次丰富的自然环境；
- **柔和**：EEVEE 的实时光照配合后期柔化（Blur / Glare）与次表面散射，画面通透柔和。

### 3.2 画面语言

- **中近景为主**：聚焦狐狸角色，同时保留足够的环境细节；
- **景深与虚化**：通过后期合成营造主体突出、背景柔化的电影感；
- **光斑（Glare / 泛光）**：为高光区域（如火光、树叶间隙）添加柔和的泛光，增强氛围。

## 4. 角色设计

### 4.1 角色构成

狐狸角色由以下部件组成（对应场景中的独立对象）：

| 部件 | 对象名 | 说明 |
| --- | --- | --- |
| 身体 | `foxbody` | 狐狸主体躯干 |
| 头部 | `foxhead` | 狐狸头部 |
| 眼睛 | `foxeyes` | 眼睛部件 |
| 鼻子 | `foxnose` / `foxnose2` | 鼻子部件（含变体） |
| 尾巴 | `fox_tail` / `tail` | 蓬松尾巴 |

> 场景中存在多个带 `.001` / `.002` 后缀的重复对象（如 `foxhead.001`、`foxbody.001`、`Fox.002` 等），这些是**关联副本 / 变体**，用于不同用途或作为不同版本。

### 4.2 造型特点

- **圆润可爱的比例**：头部相对较大，身体紧凑，符合可爱角色的比例语言；
- **蓬松的大尾巴**：尾巴作为视觉重点，通过毛发粒子系统与骨骼（含 `boneStretcher` 拉伸骨骼）实现蓬松、可摆动的效果；
- **次表面散射皮肤**：身体与头部材质启用了 Subsurface Scattering（次表面散射），使皮肤在光照下呈现通透、柔软的质感，尤其适合耳朵、鼻子等薄壁部位。

### 4.3 毛发设计

狐狸的毛发通过 **粒子毛发系统（Particle Hair）** 实现：

- 基础毛发 + **插值子毛发（Interpolated Children）**，增加毛发密度；
- **Clump（成簇）** 让毛发自然聚簇；
- **Kink（卷曲）** 增加毛发的自然卷曲与蓬松感；
- 毛发粗糙度（Roughness）参数用于控制毛发的散射与柔顺程度。

## 5. 场景与环境设计

### 5.1 场景布局

场景为一个**多层次森林环境**，通过多个 Collection（集合）组织：

| 集合 | 内容 |
| --- | --- |
| `GRScene` | 场景主集合 |
| `GRFox` | 狐狸角色 |
| `GRTreeBig` / `GRTreetrunk` / `GRtree` | 大型树木、树干 |
| `GRStones` | 石头 |
| `GRMushroom` | 蘑菇 |
| `GRguibeizhu` | 龟背竹（Monstera） |
| `GRzonglvshu` | 棕榈树 |
| `GRenvironment` | 环境植被 |
| `GRfire` | 火焰 |
| `GRlight` | 灯光 |
| `GRparticles` | 粒子系统 |
| `GRskin` | 皮肤/角色相关 |

### 5.2 环境元素清单

| 元素 | 说明 |
| --- | --- |
| 树木 | `tree1`、`treetrunk`（树干）、`treestump`（树桩） |
| 蘑菇 | `mushroom`（及其 5 个变体 `.001`–`.004`） |
| 树叶 | `leaves` |
| 苔藓 | `moss`、`moss2` |
| 草地 | `babygrass`（小草）、`cucao`（粗草） |
| 龟背竹 | `guibeizhu`（龟背竹，含 6 个变体） |
| 棕榈树 | `zonglvshu`（棕榈树） |
| 蝴蝶 | `butterfly` |
| 火焰 | `fire` |
| 地面 | `dimian`（地面）、`Plane` |
| 石头 | `Stones` 集合 |

环境设计的特点是**植被种类丰富、层次分明**，既有高大的树木与棕榈树，又有地面的小草、苔藓、蘑菇与落叶，营造出郁郁葱葱、富有生机的森林氛围。

## 6. 动画设计

### 6.1 动画对象

项目中存在以下动画 Action（动作）：

| Action | 绑定对象 | 作用 |
| --- | --- | --- |
| `fox_tailAction` | 狐狸尾巴 | 尾巴摆动动画 |
| `Fox.002Action` | Fox.002 对象 | 角色整体动画 |
| `EmptyAction` | Empty | 辅助动画 |
| `Empty.001Action` | Empty.001 | 辅助动画 |
| `Empty.002Action` | Empty.002 | 辅助动画 |
| `Empty.003Action` | Empty.003 | 辅助动画 |

### 6.2 动画设计要点

- **尾巴动画**：通过 `boneStretcher`（拉伸骨骼）实现尾巴自然的摆动与拉伸（Squash & Stretch 原则）；
- **Empty 辅助对象动画**：多个 Empty 对象被用于**相机运动控制**、**蝴蝶飞行**、**火焰闪烁**等辅助动画——这是 Blender 中常见的"用空物体做控制器 / 父级"的做法；
- **相机动画**：相机（`Camera`）通过 Empty 对象进行推拉摇移，实现镜头运动。

## 7. 材质与纹理设计

### 7.1 材质工作流

项目采用**标准 PBR（物理渲染）工作流**：

- **基础色（Base Color）**：漫反射颜色 / 贴图；
- **粗糙度（Roughness）**：表面粗糙度；
- **法线（Normal）**：法线贴图，增强表面细节；
- **置换 / 凹凸（Displacement / Bump）**：树皮等表面的立体感；
- **次表面散射（Subsurface Scattering）**：狐狸皮肤的透光质感。

### 7.2 角色材质

狐狸角色材质（`skin` / 各身体部件）核心是 **Principled BSDF（原理化 BSDF）** 节点，并启用：

- **Subsurface Weight / Scale / Radius / IOR / Anisotropy** —— 完整的次表面散射参数组；
- **手绘贴图**：`head.png`、`body.png`、`tale.png`（尾巴）等狐狸专属贴图，为角色提供基础色与细节；
- **Noise（噪声）纹理**：用于皮肤次表面散射的细微变化（`Noisy Image`），使皮肤更自然。

### 7.3 环境材质

环境材质使用 **ambientCG（原 CC0 Textures）4K PBR 贴图**：

| 贴图 | 用途 |
| --- | --- |
| `Wood059_4K_Color / Roughness / Normal` | 木材（树干、树桩） |
| `Bark001_4K_Color / Roughness / Normal / Displacement` | 树皮（含置换贴图） |
| `forest.exr` | HDRI 环境光照 |

> `Wood059`、`Bark001` 是 ambientCG 素材库的经典 ID，说明项目使用了开源 PBR 素材。

### 7.4 材质节点构成

从 `.blend` 文件中可识别的着色器节点包括：

- **Principled BSDF**（原理化 BSDF）—— 核心着色器；
- **Image Texture**（图像纹理）—— 贴图采样；
- **Texture Coordinate**（纹理坐标）—— UV 坐标；
- **Mapping**（映射）—— 纹理映射变换；
- **Separate XYZ**（分离 XYZ）—— 通道分离；
- **ColorRamp**（颜色渐变，`ValToRGB`）—— 颜色映射与过渡；
- **Mix**（混合）—— 颜色/数值混合；
- **Texture Gradient**（渐变纹理）—— 渐变效果；
- **Emission**（自发光）—— 火焰等自发光材质；
- **Normal Map**（法线贴图）—— 法线贴图解析；
- **Noise / 噪声纹理** —— 随机细节。

这些节点的组合表明材质设计**层次丰富**，并非单一的贴图 + BSDF，而是带有渐变、混合、分离通道等进阶处理。

## 8. 灯光与氛围设计

### 8.1 光照方案

- **HDRI 环境光**：`forest.exr` 作为世界环境（World）贴图，提供整体的森林环境光照与反射；
- **多盏人工灯光**：场景中存在多盏灯光对象（多个 `LA` 灯光，如区域光 / 点光），用于补光与局部强调（如火光、角色主光）；
- **火焰自发光**：火焰材质使用 Emission（自发光）节点，为场景提供暖色点光源氛围。

### 8.2 氛围设计

- 整体采用**暖色主光 + 冷色补光**的经典布光思路；
- 火焰作为**暖色点缀**，与森林的绿色植被形成冷暖对比；
- 通过后期 Glare（泛光）让火光、高光区域产生柔和光晕，增强氛围。

---

## 9. 色彩设计

### 9.1 主色调

- **绿色系**：森林植被（树木、草、苔藓、龟背竹）构成画面的绿色基调；
- **暖橙色 / 棕色系**：狐狸的毛发、树皮、火光构成暖色点缀；
- **肤色通透感**：狐狸皮肤通过次表面散射呈现柔和的暖肤色。

### 9.2 色彩对比

- **冷暖对比**：绿色环境（冷） vs 狐狸毛发 / 火光（暖），使角色与火焰成为视觉焦点；
- **明暗对比**：通过灯光与后期，使主体（狐狸）与背景形成明暗层次。

---

## 10. 镜头与构图设计

- **中近景构图**：突出狐狸角色，同时保留环境细节作为叙事背景；
- **相机运动**：通过 Empty 控制器驱动相机推拉摇移，营造运动镜头；
- **景深与虚化**：后期合成中的 Blur（模糊）用于模拟景深，突出主体。

---

## 11. 后期处理设计

项目的**合成器（Compositor）**包含以下后期节点，构成完整的后期流程：

| 节点 | 作用 |
| --- | --- |
| `Blur`（模糊） | 柔化 / 景深模拟 |
| `Glare`（泛光） | 高光泛光、光晕（Bloom） |
| `Color Balance`（色彩平衡） | 整体色调统一 |
| `Denoise`（降噪） | 渲染降噪 |
| `Lens Distortion`（镜头畸变） | 模拟镜头畸变，增加真实感 |

这些后期处理统一了画面色调，柔化了高光，增强了电影感。

## 12. 制作流程

综合以上设计，本项目的整体制作流程为：

1. **角色建模**：狐狸身体、头部、眼睛、鼻子、尾巴的建模；
2. **骨骼绑定**：为狐狸建立 Armature（骨架），含 deform 变形骨骼与尾巴拉伸骨骼；
3. **毛发制作**：使用粒子毛发系统为狐狸添加毛发；
4. **材质制作**：PBR 材质 + 次表面散射皮肤 + 手绘贴图；
5. **环境搭建**：树木、植被、蘑菇、苔藓、草地、龟背竹、棕榈树、火焰等环境元素；
6. **灯光布置**：HDRI 环境光 + 人工灯光 + 火焰自发光；
7. **动画制作**：尾巴摆动、角色动画、Empty 驱动的相机 / 蝴蝶 / 火焰动画；
8. **渲染输出**：EEVEE Next 渲染，输出 PNG 序列 + H.264 MP4；
9. **后期合成**：模糊、泛光、色彩平衡、降噪、镜头畸变。
